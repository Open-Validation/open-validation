# Councils to visit yourself

These councils' websites block automated downloads (bot checks, firewalls or logins), so their lists can't be
fetched by the helpers. Open each page in your browser, download the list (or use "Save as PDF" / copy the page
text) and upload it in a Claude session. Once a council is done it is removed from this list.
