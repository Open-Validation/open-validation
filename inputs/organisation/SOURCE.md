# Where these files come from

Copied unchanged from MHCLG's organisation register on GitHub:
https://github.com/digital-land/organisation-collection (folder `data/`), commit
`94533fd710fc1bb719274044e73b720e92da8f2e` (20 Feb 2025).

This is the source that planning.data.gov.uk's `organisation.csv`
(https://files.planning.data.gov.uk/organisation-collection/dataset/organisation.csv)
is built from. That download was blocked from the build machine, so the GitHub copy was used.
The LPA code is the `reference` column (e.g. `CMD`); the ONS code is `local-planning-authority` (`E60...`).
